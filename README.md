## 一、什么是 API 中转站？

API 中转站（API Relay / API Proxy）是一种架构在用户与 OpenAI 官方服务之间的代理转发服务。它在海外部署服务器节点，接收国内用户发出的 API 请求，再以合规、稳定的方式转发至 OpenAI 官方端点，并将响应结果实时回传给用户。

从技术层面看，中转站的核心价值体现在三个维度：**网络可达性**、**访问稳定性**与**成本灵活性**。对于国内开发者而言，直接访问 `api.openai.com` 往往面临连接超时、请求被拒或速率不稳定等问题；而通过中转站，这些问题可以被系统性地规避，从而保障业务的连续性与可靠性。

```python

    api_key="your_api_key",
    base_url="https://37chatgpt37.com/v1"  # 替换为中转站地址

```

仅需修改 `base_url` 一行代码，即可将所有 API 调用无缝切换至中转站，原有业务逻辑零改动。
